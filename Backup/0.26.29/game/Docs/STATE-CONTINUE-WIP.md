The shared generic state controllers now sample continue before actor mutation and return transition/continuation metadata. The Helper executor consumes that outcome rather than unconditionally stopping whenever the entry generation changes. Current-state changes synchronously flush the incoming header/body before an enabled old-body continuation, while hitpause retains the selected header and continues only eligible old instructions. Global changes continue their old global body before the action's normal header initialization.

Each actual Helper body retains its original controller schedule across a nested transition, and continuation updates the observed entry generation without dropping later old-body instructions. The selected-state flush uses a native-backed bounded nesting loop, avoiding recursive calls on every state-chain link. Full native VM/persistent/limit-edge fidelity remains Pending.
