The actual parser now validates exactly three arguments: source literal clsn1/clsn2/size/dummy, a numeric target-player ID expression, and target literal clsn1/clsn2/size. Quoted/numeric/all/none groups and target dummy are rejected, as in the pinned compiler. ID expressions evaluate once in original-caller scope under redirection, with native integer conversion. The numeric expression engine preserves the query's boolean type.
