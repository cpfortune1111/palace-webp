# 0.25.45 — Reaction SelfState parameters and provider execution (partial)

Release checkpoint: the extended reaction harness passes 44 cases, including this work and later animation headers. The complete combined browser suite and all 189 Node checks pass. Chronological unpublished-stage observations below are retained as evidence; deployment is verified separately. Full controller/native-VM certification remains Pending.

Reference: Ikemen GO cb56d73badb322f3725257c2e8cfd157b2c3989d, bytecode.go SelfState.Run and char.go changeStateEx. This work follows the numeric parameter/order semantics already used by the generic controller consumer; it does not certify the whole controller.

Reaction SelfState previously bypassed the generic consumer: it cleared providers and entered a header using only value. Numeric ctrl/anim, continue and readplayerid were therefore not consumed on that path. The generic consumer now has a reaction-specific self-state destination adapter, retaining the recipient object while reusing actual parameter sampling/control/animation ordering. The adapter selects the requested actor's own character program, preserves the recipient's animation ownership when borrowing, and executes the incoming reaction body through the real current-body chain. Both old tails continue only when requested.

Body execution now re-enters the selected provider scope rather than remaining in the previous borrowed program. A stronger conflicting-provider fixture also exposed an ending-physics lookup in the abandoned provider after the body returned. That lookup now uses the selected provider: a native C header applies friction, while an N header does not. This fixes a real provider consumer rather than merely copying a state-owner label.

`Tools/check-root-reaction-entry.cjs` now contains 24 reaction-runner cases: four imported trip trajectories, ten ChangeState/SelfState stop/continue/same-generation cases, two first-action aerial-physics cases, and eight Saturn/Moon SelfState reader cases. The reader cases start in borrowed programs, distinguish own/self/other/invalid IDs, check pre-mutation continue evaluation, normalized control, numeric animation before an omitted header, immediate Time=0 markers, both old tails, provider/animation ownership and conflicting ending physics. They are real reaction-runner consumers, not full simStep equivalence. Failing-before evidence: outputs/reaction-self-state-before.log and outputs/reaction-self-state-provider-before.log. Passing focused evidence: outputs/reaction-self-state-provider-after.log.

Remaining work includes RedirectID/stop ownership, animation prefixes, complete native selected-header and hitpause phases, non-reaction destinations, broader animation/coordinate semantics, the full expression VM and all native action ordering. No controller is certified and this checkpoint is not yet published. Original Moon throws, generic SelfState readers and complete browser regression remain separate gates.
