# Guard-distance Const expressions — local partial checkpoint

Pinned reference: Ikemen GO cb56d73badb322f3725257c2e8cfd157b2c3989d. compiler.go around 2171–2198 exposes normal/projectile attack distance legacy names and six explicit width/height/depth components each: fourteen names including aliases. bytecode.go around 2753–2780 reads the subject's Size values and converts to the compiled expression's units using (320 / subject localcoord) / expression localscl.

Engine/guard-distance-constants.js implements those fourteen names with float32 component and coordinate-ratio arithmetic. Unknown names remain unhandled for the existing constant dispatcher; they are not silently mapped to zero. Tools/check-guard-distance-constants.mjs covers every name/alias, case normalization, all axes, caller-unit conversion, unknown names and invalid coordinates.

The live expression context now carries a constant-reader closure that retains the subject actor and original expression owner through redirection. Helper(id) redirection also preserves that owner instead of replacing it with the Helper. Subject Size comes from the root's own profile or the Helper's creation snapshot; snapshots now include localcoord. Expression units come from the executing state provider, including foreign-state programs, independently of the subject's own character units. Other Const families retain their existing implementation and remain outside this checkpoint's parity claim.

An actual browser fixture extends the existing parent/child/projectile snapshot checks with a foreign state provider using 320-wide units and a subject using 1280-wide units. It asserts root Size 720 becomes Const 180, the Helper's own program reads its retained 240, and the foreign caller's Helper redirect reads 60. Those assertions and the complete regression passed with terminal exit 0 in outputs/controller-guard-distance-constants-browser.log. An initial run caught an out-of-scope fallback variable in the new context closure; the fallback now explicitly selects fighterPlayer(fighter).

Negative-state integration now supplies explicit own-character guard-distance Const units to root State -4/-3/-2 execution. P2 lifecycle dispatch preserves the supplied context rather than rebuilding it from the current borrowed state. Own State -3 is skipped while the root uses a foreign state provider, matching char.go actionRun's state-player ownership condition. Helper negative states fetch their own character's programs through a separate ownData binding, and evaluate these constants in that program's units rather than the root's current foreign provider. Ordinary Helper state guard-distance expressions retain their state-provider units. Other query families still need their own coordinate/provider audit.
