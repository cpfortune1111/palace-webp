# 0.25.44 — ForceFeedback output consumer (partial)

Pinned reference: Ikemen GO cb56d73badb322f3725257c2e8cfd157b2c3989d, src/bytecode.go forceFeedback.Run, src/system.go legacy feedback update, src/input_sdl.go RumbleController.

Generic root/Helper controllers and source reaction bodies use a shared consumer. RedirectID is evaluated before ordinary parameters; the old API evaluates time, frequency/amplitude vectors and self, selects the opponent when requested, and excludes Helper output. New lo/hi values use uint16 conversion, bypass the old self redirect, and support the ultimately redirected actor. Old effects retain per-controller clocks and route sine/square/sinesquare/off into real dual-rumble browser requests. The pinned implementation evaluates but does not otherwise consume frequency, so no invented frequency behavior is claimed. Its third amplitude term uses the already-powered second term; this source behavior is retained rather than silently corrected.

The browser backend converts native ticks to milliseconds with the pinned SDL frame rounding and half-frame buffer, handles zero-duration stopping and unavailable/rejecting actuators without stopping combat. Current browser device selection maps root player slots to the corresponding Gamepad index. Complete user-configured input remapping, physical-device measurements, platform-specific multipliers, and full version/expression parity remain Pending. No connected compatible gamepad means no physical output; tests do not claim that a mocked actuator proves hardware fidelity.

`Tools/check-force-feedback.mjs` tests old/new values, motor routing, redirects, Helper distinction, timing and browser requests. `Tools/check-force-feedback-browser.cjs` exercises actual root controller dispatch into mocked navigator Gamepad actuators for both slots. Original Moon throw regression passes through the newly supported recovery controller. The legacy Helper prefilter is no longer used, avoiding duplicate expression evaluation before the real consumer. This controller remains uncertified, and these changes are not yet released.
