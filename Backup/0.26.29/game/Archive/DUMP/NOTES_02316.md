# 0.23.16 — Shared Expression / P2 Key M1

0.23.15 使用者 PASS。下一切片統一雙方 State 200 的 CNS 表達式評估：P2 不再維護另一份 AST evaluator，兩邊共用 evalM1／evalAST／controllerTriggered 與語法 cache。

P2 使用自己的 Time／AnimElemTime／Random／var／sysvar／MoveContact／MoveGuarded 與 command context；cache 只保存語法樹，不保存判定結果。未知 query／function／CMD name 明確報錯；布林短路與 ifelse 保持 lazy evaluation，避免读取不應執行的分支。Const 沿用同一 Venus 來源常數。

鍵盤 U 接入同一「P2 出拳測試」單次請求，右上按鈕保留。U 長按不連發；輸入欄／選單、Ctrl／Alt／Meta 組合鍵及手動 Touch mode 不觸發；Auto mode 可切回鍵盤。失焦／切換模式清除尚未消費的請求。Trace 增加 physicalInput.p2Punch 脈衝，仍不是完整 replay。

驗證：逐個 State 200 tick × Random 0/249/250/999 × 8 controllers，比對 P1/default 與 explicit fighter context 判定；另驗 var／sysvar／clock／command／local VX 隔離、cache 更新、短路、未知表達式拒絕。U 出拳、長按防連發、模式／選單／組合鍵／失焦及 trace 脈衝驗證通過，保留完整舊版回歸。

範圍：U 是 Web 測試輸入映射，不是原 CNS 新增 command。未新增 P2 移動／完整 CMD runner／同時攻擊 trade／空中受擊；既有 HitDef、hitshake x2、角落推退、素材與鏡頭不變。下一步才統一更多 controller handlers 和 P2 移動輸入，不宣稱完整執行器已完成。
