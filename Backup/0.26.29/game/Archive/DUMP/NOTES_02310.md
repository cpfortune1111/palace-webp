# 0.23.10 — Ground Cornerpush M1

0.23.9 使用者驗收：PASS。本版只補 P1 State 200 / P2 地面命中與防禦切片的 cornerpush。

## 來源
- Venus CNS State 200：ground.cornerpush.veloff=-24、guard.cornerpush.veloff=-28。
- Venus DEF 無 ikemenversion；來源亦無 legacy.cornerpushdefaults override。依已核對 IKEMEN src/char.go finalizeParams 的 legacy 分支，未指定 velmul 時使用 0.7，不擅自改成站立 friction 0.85。
- 同一 IKEMEN checkCornerPush：有效受擊 target、預測下一位置是否受屏幕限制、扣除 target 此 tick 能移動的距離、無 target 清除、position 更新後衰減。
- stop threshold 對照 originLs = localscl * 320 / gameWidth。這個切片使用 Venus 1280 原座標，因此 1/originLs=4 source units。

## 實作
- cornerpush 是獨立的世界方向位移，不改寫 CNS/local VX，不隨轉身重新翻轉。
- 使用既有 camera / player / screen margins 算同一組 screen limits，不另加 Web-only edge calibration。
- HitDef contact 設定 cornerpush；hitpause 時不消耗或套用。受擊／防禦 target 存在時依 source mul 衰減，非角落不推；目標恢復 I 時清除。
- HUD 增加 CP(world) signed 值，方便辨認 VX=0 時的 cornerpush 位移。

## 驗證
- 左右 stage corners × 命中／站防：-24／-28 符合 facing，hitpause 8 ticks 期間不移動，之後 attacker 退開，P2 不越界，CP 最終歸零。
- 近角落剩 10 units 可移動：-24 cornerpush 扣除 10，只推 -14。
- 舞台中央不額外推移、無有效 target 清除。
- 0.23.9 的 CLSN、priority、5001 animation、signed HUD、24 個 turn pixel checks、stage edge backward jump、cancel、重入及 30/60/120 Hz 回歸全通過。

## 邊界
仍是單一 P1→P2 地面 target，非完整雙向引擎。Projectile、helper、多 target、SuperPause／NoCornerPush／特殊 screenbound assertions、空中／倒地 cornerpush 尚未接入；本版不以猜測補這些分支。無空中防禦規則不變。
