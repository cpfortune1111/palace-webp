# 0.23.11 — Guard Continuity / Hitshake M1

## 使用者驗收
0.23.10 角落命中／防禦推退：PASS，保持不變。

## 連續防禦
第二拳變成命中是 Web 判定錯誤，不是作者新增 guard break 系統。舊判定要求 p2.ctrl；Common State 151/153 在 guard hittime 內 ctrl=0，直到 GetHitVar(ctrltime) 才恢復，因此第二拳會被當成無防禦。

對照 IKEMEN char.go Guarding instructions / inGuardState：一般地面 idle+ctrl，或已在 guard state，都能在持續 back/autoguard 條件下保留防禦。修正為 ctrl+MoveType=I 或 ground guard states；不把真正的受擊 5001 當成可以重新防禦。P2 選單仍只是 ground guard test input，空中防禦禁止不變。

## 視覺 hitshake
IKEMEN char.go 的 Hitshake effect 在 hitshaketime>0 且 state time 為奇數時，charSD.pos.x 減去 facing。這是 sprite-only offset，不改物理 Pos X、碰撞框、camera 或 cornerpush。

核對使用者 Moon Palace save/config.json GameWidth=1280、GameHeight=720 與 data/system.def localcoord=1280,720，本切片用 -facing 的 1 logical world unit，未憑截圖猜放大幅度。停頓期間保留 P2 hitshake time parity；Pause/Step 讀同一份 P2 snapshot。

ForceFeedback 不是此 sprite-only draw offset 的來源；不以 ForceFeedback waveform 值猜測畫面位移。本版未聲稱接入完整 ForceFeedback 周邊支援。
