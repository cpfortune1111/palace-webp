# r30：獨立分段 HP 與六角煙花

## r29 預覽的修正

r29 的2P–4P只是整條長血條上的分段輪廓，仍用一個全長裁切範圍，不能代表多人各自扣血。r30按0010遮罩的獨立連通區建立各段固定起終點，每段從自己的右端保留HP，右側以原1278anchor鏡像。每條可以獨立100%、75%、50%、25%等，不影響旁邊。

左側1280×720座標，範圍右端為不包含的像素邊界：

|版本|各段 X 範圍（左至右）|
|---|---|
|1P|160–620|
|2P|160–388；390–620|
|3P|160–311；313–466；467–620|
|4P|160–273；275–388；390–504；506–620|

每段剩餘範圍為 right-(right-left)*HP 到 right。右側範圍為1278-right到1278-left，方向鏡像。序號表示畫面段落，不預先指定未來角色隊列順序。

createTiledHPBar.draw／drawTrail接受amounts陣列（0–1）；segment是可選的0起始單段索引。amount純量在多人版本代表每段相同比例，不再當成整隊全長比例。底圖／邊框仍一次繪製整個版本。HUD render可用hpBarVariants、hpBarAmounts、hpTrailAmounts傳入兩側資料；未傳陣列時現有1P戰鬥沿用原扣血／延遲邏輯。

預覽增加四條獨立HP滑桿及各段X範圍；現有遊戲沒有因此新增多人戰鬥或接入未完成角色。

## 新增勝出煙花

沿用原圓形／角色符號雙形、每發隨機單色、六發上限及所有尺寸／拖尾／旋轉設定。

|角色|裙／服裝主色|胸前蝴蝶結／服裝輔色|
|---|---|---|
|Mercury|#137BC3|#8EDDF5|
|Mars|#E33F43|#7746A9|
|Uranus|#203E9C|#F6D150|

參考現有角色大頭像。Pluto黑裙提升為灰紫方便夜空顯色；SWA以服裝紫／金代表雙色。符號沿用原Firework檔。合共11角色煙花設定已齊備，預覽可選全部；這不是六角色戰鬥接入。

## 驗證

左右兩側2P／3P／4P逐段清空共18組，均只改該段、旁邊像素完全相同；四種輪廓的半血、零血、鏡像、連續平鋪循環通過。11角色均見兩形／兩色、符號正確、每發單色、六發上限、原尺寸／落速範圍。現有1P HUD扣血、延遲血條及計時回歸測試通過。

上次純透明邊裁切也已全部發佈，r29最終18個公開檔案核對通過。
