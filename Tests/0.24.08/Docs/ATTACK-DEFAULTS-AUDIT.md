# 五角色招式預設值核對 — 0.24.08-r17

省略 optional parameter 並不等於原檔有 BUG。Web 必須套用相應預設；required parameter 缺失才應報錯，不能隨意補值。

核對範圍：現時試玩版五個角色所有已編譯 HitDef / Projectile 定義（去除不同 runtime 分組內完全相同嘅副本），包括 helper 內嘅招式及保留但未必 SNES 可觸發嘅分支。不代表新增 3DO 接入。共 119 個定義；另盤點 3193 個其他 controller。原檔保持不變。

參照本機固定版本 IKEMEN GO src/char.go：HitDef.clear、HitDef.finalizeParams、Projectile.initFromChar。五個角色 .def 均為 mugenversion=1.0、localcoord=1280,720，故採用 MUGEN 相容分支。數值 yaccel=0.35、fall.yvelocity=-4.5 由原生 320 座標換算為現有 1280 座標嘅 1.4 / -18。
