# r28：AI 防禦退出與行走轉向限制

按作者決定，只限制兩種主動行為，不更改原距離門檻、招式機率或威脅判斷。

- AI 進S120後，A120／A121起手未完成前，不允許主動ChangeState去S140。適用原Common controller路徑與舊防禦適配路徑，避免同tick進120再退出、畫面只見A0→A140。起手播完後按原條件繼續防禦或退出；不強制停留A130。
