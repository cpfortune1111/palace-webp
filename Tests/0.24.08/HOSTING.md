# Moon Palace 0.24.08 test page

R4 adds a circular main menu: the current item and its two neighbors remain clear, with more distant items fading at the edges. Arrow keys animate the list; pointer dragging scrolls it and only a short stationary tap activates an item. The selected item emits the Mercurius Sudoku eight-point cursor spark (lossless WebP), with its original short lifetime, drift and rotation directed left and right. Menu navigation uses the compressed btn-select Ogg. Report Card uses the updated transparent pattern over #E7C7FF. Projectile hits accepted by a helper's HitBy/HitOverride now consume the projectile contact as well, so Moon Tiara and Saturn Press Crusher both finish their collision animations. No Moon LOSE/TLose timelines changed.

R3 adds animated selection, ACS, intro and result portraits for Moon, Jupiter, Neptune and Saturn. Open portrait-review.html to replay each presentation without a match. Images are cropped WebP with a logical 1280×720 canvas; voices are compressed Ogg Vorbis. Only the selected characters' declaration assets are prepared before battle. Selection and ACS share the same animation clock on handoff.

Moon and Jupiter complete their silent victory pose transition before speaking. Moon defeat loops the crying animation without lip sync. Time-over defeat uses TLose; Moon TLose 02a and 02b play sequentially. Other speaking sections use three mouth shapes driven by voice loudness, rather than phoneme recognition. Data/Quote/*.json contains editable 60 Hz timelines. Tools/build-quote-portraits.py rebuilds the compressed assets from the private Quote folders, with Pillow, NumPy and SoundFile installed. Original PNG and WAV files are not included.

R2 removes the old result-state watchdog entirely: no animation-loop rescue may force S0 and bypass source cleanup. Jupiter's 3005→3006→3007→0 chain removes E9066 under KO and time-over for both players. Supplemental WebP sprite sheets for Jupiter, Neptune and Saturn supply native SFF sprites referenced by Moon's foreign A805; they do not replace its AIR elements, timing or collision table. The sprite supplements are loaded with the selected characters. B1-9-CHECK.md records the five-character usage audit; none of the nine generic changes were imported.

Open index.html over HTTPS. The launcher installs an asset router scoped only to this test directory, then opens game.html.

The original baseline is commit 5e65ded09d5c645c7ef2ed4b088f3b957b94138f. R1 changes only game.html and adds Engine/baseline-fixes.js for the requested post-KO effect binding/independent hitpause, finish-state facing and ChangeAnim2 sprite ownership fixes. asset-map.json still routes unmodified historical files to frozen backup files with identical Git blob hashes. No current main-game or WASM code is substituted. BUG-CANDIDATES.md lists optional later fixes that have not been applied.

The launcher/router are hosting infrastructure only. Apart from the three R1 fixes, gameplay, assets, timing and known bugs remain those of 0.24.08. This is a baseline for user testing, not a performance certification. The existing Three.js CDN dependency is retained.
