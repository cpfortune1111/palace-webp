# Hitflag — partial live collision integration

Reference: Ikemen GO `cb56d73badb322f3725257c2e8cfd157b2c3989d`, `src/char.go` attrCheck at line 11066 and inGuardState at line 9991.

`Engine/hit-flag.js` implements the native S/C/A/L mask tests, F/falling rejection, source NoFallHitFlag, minus hit-state rejection and plus hit-state/guard-state restrictions. Its semantic interface requires explicit integer hit-state status; tests include -1, zero, one and two. The guard-state predicate uses the exact native state list, not every number in 120–155.

The ordinary live collision adapter now calls this predicate rather than its old limited string test. Removed the blanket lying-state rejection so an explicit D flag can reach actual overlap checks. NoFallHitFlag is registered with existing real actor assertion storage, redirect and per-frame reset mechanisms; focused tests cover redirected enable/disable. A real imported-animation collision fixture covers D, plus/minus, guard exclusion, F and NoFallHitFlag. Its full browser result is tracked separately.

`hit-state-store.js` now retains independent actor state instead of re-reading changed MoveType for every collision. The first actor finish/contact qualification samples a tick; later contacts in that tick preserve that status. Non-H positive status clears only with an allowed actionRun, H status samples fall even during hitpause, and a selective Reversal recipient callback changes zero to -1 without replacing positive status. Round reset clears the store and destroyed Helpers release their entries. Focused tests cover these transitions and a live adapter fixture is added separately.

The original live hitflag geometry regression and the first status-snapshot regression both completed with exit 0 (`outputs/controller-hitflag-live-collision-browser.log`, `outputs/controller-hitflag-state-snapshots-browser.log`). A further runtime fixture verifies same-pass 0 despite a later H/fall change, next-tick falling 2, pause-held recovery, nonpaused clear and reversal -1 persistence. Another spawns a Helper and executes DestroySelf to verify status cleanup. The complete regression including these fixtures also ended with exit 0 (`outputs/controller-hitflag-status-lifecycle-browser.log`).

Important pending behavior: the WEB driver's interleaved actor/controller/collision order is not the complete native Prepare/Run/Finish/update/globalCollision scheduler. Sampling at existing actor hooks therefore remains a partial phase adapter, not proof of native full-frame timing. Complete per-actor phase placement, guard/version regressions, general Helper collision routing and full cross-profile semantics remain required. This work must not be counted as complete HitDef hitflag or AssertSpecial certification.
