# Helper entry bootstrap (partial)

Pinned source: Ikemen GO cb56d73badb322f3725257c2e8cfd157b2c3989d. Reviewed helper.Run defaults, newHelper, helperInit and changeStateEx. Native helperInit calls changeStateEx(st, playerNo, 0, 1): animation 0 and control enabled precede the target StateDef. Velocity is cleared. newHelper initializes life and maximum life from the parent's maximum, rather than current damaged life.

The shared entity constructor previously read projanim for Helpers, producing NaN when a StateDef omitted anim or used -1. It also defaulted control to zero, accepted inherited constructor velocity and fixed life at 1000. Actual Helper creation now initializes animation 0, control 1, zero XYZ velocity and inherited maximum life before entering the requested StateDef. Explicit StateDef animation/control/velocity override the bootstrap; anim -1 keeps animation 0.

Omitted stateno and id now default to zero. Their integer expressions evaluate once in the caller context; a negative Helper ID is warned/clamped before the target StateDef consumes it. Native newChar starts at minus=3, so helperInit's changeStateEx buffers StateDef entry; its negative-ID normalization therefore precedes actionRun's stateChange2. The game's user-requested suppression of H950 remains, including state expressions evaluating to 950. This game-specific suppression is not presented as native Helper compatibility.

Evidence: 24 browser combinations across character versions, both players, root/nested parents and omitted/-1/explicit StateDef animation forms exercise actual sprite pixels and expression values. Additional checks cover omitted state/ID, expression side effects, negative IDs and H950 suppression. Projectile-versus-Helper contact tests now pass without forcing the target's animation from the fixture.

Helper redirect, standard postype/XYZ/facing and pause-field consumers now have actual mixed-coordinate tests; see HELPER-PLACEMENT-WIP.md. Name defaults/expressions and actual HelperName queries now have consumers too; see HELPER-NAME-WIP.md. Pending: full native compiler evaluation order across all Helper fields, remaining space/provider/constructor edge cases, native child registration/first-body execution timing, initial StateDef/animation edge cases and executable differential certification. No whole-Helper certification changes. Character recoloring remains excluded; gameplay palette effects remain. No original assets or new media are added.
