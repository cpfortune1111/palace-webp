The shared generic ChangeState/SelfState consumer now applies the controller's explicit control setting before entry, allowing the incoming StateDef control field to win as in native changeStateEx. Negative control arguments retain control; nonnegative integers normalize to a boolean rather than storing -1 or 2 in Ctrl. It no longer overwrites the already-executed header afterwards. The generic root and Helper paths use this ordering; special reaction/source adapters remain separately subject to the complete parity audit.

Helper general changes use the actual selected-state buffer. IgnoreHitPause changes select metadata/control while retaining old header fields until hitpause ends. Own global changes initialize after negative programs in the same eligible action; ordinary current-state changes initialize and execute the incoming Time=0 body within that action. State-entry generations distinguish re-entry into the same state number from no transition. Current-state chains stop the old body and run the new body, with a bounded loop based on the native MaxLoop constant. Automatic Helper get-up also consumes this current-state phase. Complete limit-edge/error/persistent semantics remain Pending.
