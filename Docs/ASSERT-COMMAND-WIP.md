The shared root/Helper controller path now validates the compiler's quoted static name, resolves redirectid, evaluates buffer.time as signed int32 (default 1), and writes actual command-list buffers. It overwrites rather than taking the maximum, updates duplicate names case-sensitively and warns for invalid names. Empty name selects a command-name group randomly; nonpositive requested time then uses that group's first command bufferTime, falling back to one. The WEB random choice uses the existing host RNG, not a certified native RNG sequence.
