Native panning multiplies the existing stereo channels independently with linear gains, not the equal-power crossmix law of Web Audio StereoPannerNode. `Engine/linear-sound-panner.js` implements float32 clipped pan/gain and per-channel gain limits using explicit two-channel speaker upmix, a splitter, independent gain nodes and a merger. Mono sources upmix before channel splitting.

`Tools/check-linear-sound-panner.mjs` checks gain math, graph routing, configuration and disconnect. Eight actual OfflineAudioContext renders exercise mono/stereo sources at pan -1, 0, .5 and 1 and assert decoded output samples (`outputs/linear-sound-panner-browser.log`). This is rendered audio evidence for the primitive, not production SndPan controller coverage or audible-device playback.

`Engine/sound-pan-state.js` adds native float32 facing/local-scale capture, source position retention after emitter removal, relative camera scaling, absolute screen-width pan, strength and stereo-disable behavior. `Tools/check-sound-pan-state.mjs` verifies these calculations, including unclipped intermediate pan (gain output clamps later) and quoted-string zero extraction. This is executable semantic groundwork, not a production consumer: no controller is counted implemented from these tests.

`Engine/sound-pan-controller.js` now validates the required channel, resolves typed optional redirect before reading payload expressions, evaluates pan before abspan and allows abspan to override pan while preserving both evaluations.
