# ModifyExplod — partial random/selection consumers

Pinned reference: Ikemen GO cb56d73badb322f3725257c2e8cfd157b2c3989d, bytecode.go modifyExplod.Run and char.go getMultipleExplods. Native selection evaluates redirect/id/index before other operands, skips remaining evaluation when no match exists, samples random components once and commits the same offsets to every selected effect. MUGEN characters lock random without a postype declaration; postype also resets relative coordinates, velocity/acceleration and zero bindtime before modifier commits.

The shared dispatcher now has a real ModifyExplod consumer for owned ID/index selection, redirectid, random and postype=p1. Actual source effects update XYZ coordinates/bind offsets, and native MUGEN reset behavior is distinguished from Ikemen character behavior. Sixteen real root/normal-Helper/profile/player/character-version cases use two own/common effects, checking common samples, selection short circuits, index isolation, version gates, reset behavior and draw-queue output (outputs/modify-explod-consumers.log). Independent checks cover caller-to-recipient scale and interleaved expression/sample order.

Position, velocity/vel and acceleration now have deferred XYZ extraction with recipient scale conversion; scale has independent partial XY writes. Native MUGEN locks suppress position/motion expression evaluation without postype but do not lock scale. Modified source effects use float32 XYZ motion/acceleration integration without changing unmodified legacy effects. The sixteen actual cases now also verify world positions, velocity/acceleration after a real effect step, unchanged motion during a scale-only update and real drawing-matrix scales. Independent tests verify redirected dimensional conversion and unlocked partial scale defaults (outputs/modify-explod-motion-consumers.log).

Friction now has real unlocked XYZ writes, including native zero defaults for omitted Y/Z components. Modified-effect motion first advances position, then multiplies velocity by friction, adds acceleration and stops speeds below float32 0.1 only when absolute friction is below one. Independent motion checks and the sixteen actual cases verify movement order, scaling/acceleration, partial-axis defaults and the stop threshold (outputs/modify-explod-friction-consumers.log). Unmodified legacy effect integration remains unchanged.

Forty controller-specific actual scheduling groups now verify root current/global/lifecycle and normal Helper current/global hitpause, persistence and global-pause movement allowances in both profiles/player directions. Each attempt observes a real seeded common Explod, resets its scale, and requires the effect to remain in the live collection with the expected update; stale/removed references do not pass. The expanded ten-controller matrix has 400 groups (outputs/modify-explod-specific-scheduling.log).
