# Debug clipboard controllers — 0.25.51 partial checkpoint

References: MUGEN 1.1 DisplayToClipboard/AppendToClipboard/ClearClipboard reference (https://www.elecbyte.com/mugendocs-11b1/sctrls.html); pinned Ikemen GO cb56d73badb322f3725257c2e8cfd157b2c3989d, displayToClipboardSub, the three controller Run methods, Char.appendToClipboard and common.go OldSprintf.

The former DisplayToClipboard no-op is removed. Display, append and clear now execute through the real common controller path for roots and Helpers, store actor-isolated debug text and display it in the in-game debug HUD. This is not the operating system clipboard. RedirectID selects the output recipient before parameter evaluation; parameters remain caller-scoped and execute once, left to right. Invalid recipients skip parameter evaluation. Display replaces, clear removes, and append preserves existing text.

Documented MUGEN append starts a new line; pinned Ikemen append joins the first new segment to the current final line, then processes explicit newlines. Actor buffers have an explicit WEB eight-row setting, are pruned when Helpers disappear and reset on character preparation. Native configuration/lifecycle equivalence is not certified.

Supported numeric formats include d/i, f/F, e/E, g/G, literal percent, widths, precisions and basic padding/sign flags. Ikemen u aliases decimal. Unsupported verbs and native type-mismatch cases fail explicitly rather than silently ignoring text/params. Complete Go printf compatibility, all OldSprintf length modifiers, precision/rounding/undefined diagnostics, malformed strings, native debug selection/configuration and full controller/version/prefix/scheduling semantics remain Pending; none of the three controllers is certified complete.

Tools/check-debug-clipboard.mjs covers store ownership, overwrite/append/clear, row trimming, redirect sampling and supported formatting. Tools/check-debug-clipboard-browser.cjs passes eight profile/player/root-or-Helper scenarios using actual controller dispatch, real parameter side effects and visible HUD assertions. Redirected output does not redirect the source parameter writes. Complete regression and publication remain separate gates; last verified publication remains 0.25.50.

Subsequent numeric work uses exact float32 decimal coefficients rather than JavaScript toFixed/toPrecision. The pinned Go printf path uses nearest-even ties, correct significant-digit/exponent selection, negative zero and native numeric mismatch/MISSING/Undefined diagnostics. OldSprintf's single length-modifier stripping and i/u decimal aliases have focused tests. The existing legacy numeric path retains halfway-away behavior, with Windows MSVCRT reference observations for large fixed values and alternate-form zero.

Tools/fixtures/clipboard-crt-float32.json records sixty independently generated Windows msvcrt _snprintf outputs for real float32 bit patterns promoted to C varargs. Raw outputs are retained; exponent padding is explicitly normalized to two digits in this numeric gate. Tools/check-clipboard-float32-format.mjs covers ties, subnormals, negative zero and maximum finite float32. This is not execution of MUGEN or the pinned Go binary, and it does not certify MUGEN rounding/exponent layout across versions. Actual browser scenarios also verify profile-specific float text and mismatch text reaches the HUD and clears.

Remaining formatting gaps include native string/other Go verbs, positional/star arguments, all malformed format/type combinations and diagnostics, full precision/flag/configuration behavior and empirical MUGEN parity. The WEB precision/width safety limits are explicit, not reported as full native support. None of the clipboard controllers is certified complete.
